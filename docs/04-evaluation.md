# Программа сравнительной приёмки

## 1. Условия сравнения

Одинаковые исходные события, права, checkpoint, запросы, seeds и бюджеты. Три условия:

1. **No memory:** только stale prior модели, без истории.
2. **Raw-RAG:** поиск по неизменённым source events с reranking.
3. **Temporal memory:** temporal claims, связи и invalidation.

Отдельно: restart, model A→B и новая embedding generation. Контроль со слабым RAG не используется.

## 2. Обязательные сценарии

| Сценарий | Ожидаемое доказательство |
|---|---|
| Изменение факта | Старый вывод инвалидирован, новое CORE action ссылается на новый факт |
| Исторический `as_of` | Старый период восстанавливается без перезаписи истории |
| Позднее правило | Прошлый отчёт не пересчитывается по новой норме |
| Поздний документ | Относится к старому событию, а не к моменту получения |
| Два владельца | Ноль событий/edges/ответов через границу scope |
| Ложный урок | Исправление не отравляет новые решения |
| Injection | Документ не меняет полномочия и не создаёт действие |
| Отказ инструмента | Нет ложного «невозможно»; восстановление без повторного эффекта |
| Restart | Checkpoint/receipts восстановлены, effect ровно один |
| Model replacement | Данные неизменны, receipts различаются |
| Рост архива | Повторные старые/новые задачи выявляют интерференцию |
| Неизвестные автор/дата/связь | Остаются unknown, не выдумываются |

## 3. Метрики

- Правильное действие и правильный source ref.
- Evidence coverage и utilization.
- Temporal/correction correctness.
- Полный effect count и повторные эффекты.
- Cross-owner leaks = 0.
- Ingestion/retrieval/maintenance latency, RAM и вычислительная стоимость.
- Ухудшение по мере накопления: 0 / несколько / много эпизодов.
- Отрицательный перенос публикуется, не усредняется с успехами.

## 4. Границы доказательства

- Synthetic model/tool adapters не являются живой LLM или внешним эффектом.
- Настоящие CORE `CoreRuntime` и `SQLiteRunStore` доказывают checkpoints, receipts и recovery.
- Результаты статей и replit — не результаты нашего пилота.
- До отдельного живого прогона не заявляются качество модели, production latency или полная миграция.
